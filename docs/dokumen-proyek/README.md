# Dokumen proyek SIKAT RTB

Bukan bagian dari aplikasi — dokumen pendukung untuk laporan/presentasi proyek.

| File | Isi |
| --- | --- |
| `FITUR DAN KEAMANAN SIKAT RTB.docx` | Fitur per peran (Mahasiswa, Satpam, Pengelola) dan bagian keamanan (hash password, sesi, rate limit login, kebijakan ganti password) — versi prosa dari [README.md](../../README.md) root. |
| [`PENJELASAN-SELURUH-FILE.md`](PENJELASAN-SELURUH-FILE.md) | Peta tiap file/folder di project ini dan fungsinya masing-masing, bahasa awam. Ditulis ulang dalam format Markdown (versi Word sebelumnya sudah basi, masih menyebut folder yang sudah lama dihapus) — tinggal salin isinya ke Word kalau perlu format itu. |

Sumber kebenaran teknis tetap [README.md](../../README.md) di root dan kode itu sendiri — kalau ada perbedaan, dokumen di folder ini yang perlu disesuaikan.
