# Bahan pendukung BAB III — Perancangan Basis Data Relasional

Folder ini isinya bukan bagian dari aplikasi — ini khusus bahan yang bisa langsung dipakai/ditempel untuk menulis BAB III proposal (Perancangan Basis Data Relasional / Database Design).

| File | Isi |
| --- | --- |
| `BAB-III-Perancangan-Basis-Data.docx` | Dokumen Word siap pakai: **3.1** Desain Konseptual & Kamus Data (10 tabel, tiap kolom ditandai Primary Key / Foreign Key / Attribute, plus penjelasan mana PK yang auto-increment vs manual) dan **3.2** Syntax SQL DDL (kode `CREATE TABLE` apa adanya, tanpa penjelasan — karena tabel memang dibuat pakai SQL, bukan manual/GUI). |
| `3.3-skema-relasi.md` | Diagram Entity-Relationship (ER) dalam format Mermaid untuk **3.3** Skema Relasi Database. Bisa dibuka di VS Code (dengan extension Mermaid) atau di [mermaid.live](https://mermaid.live) untuk melihat/screenshot diagramnya. |

Sumber datanya sama persis dengan `docs/database/schema.sql` — jadi kalau schema database berubah di kemudian hari, cukup update di situ dan file-file di folder ini bisa dibuat ulang.

Versi visual dari diagram ER (dan seluruh isi 3.1–3.3 dalam satu halaman yang enak dibaca/discreenshot) juga tersedia sebagai halaman Artifact yang tautannya dikirim lewat chat.
